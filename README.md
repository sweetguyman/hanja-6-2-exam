# 준6급(6급Ⅱ) 한자 실전 모의고사

한국어문회 전국한자능력검정시험 **6급Ⅱ(준6급)** 연습용 웹앱입니다. 아이패드·휴대폰에서 홈 화면에 추가해 앱처럼 쓸 수 있어요.

- 새 시험마다 기출(제92~114회) 문항과 배정한자 225자에서 **80문항을 무작위 출제** (실제 유형·문항 수·순서·지시문 그대로)
  - 독음 32 · 훈음 29 · 반의어 2 · 완성형 2 · 뜻풀이 2 · 한자 쓰기 10 · 필순 3
- 50분 타이머, 자동 채점, 합격(56문항) 여부, 유형별 점수, 오답 해설, 틀린 문제만 보기
- 최근 푼 문제는 기기(localStorage)에 기억해 되도록 다시 안 나오게 함
- 배정한자 카드(급수별, 카드 넘기기/한눈에 보기)

## 개발
```
npm ci
npm run dev
npm run build
```
`main`에 push하면 GitHub Actions가 GitHub Pages로 배포합니다.
